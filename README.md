# Student Lost & Found

A university platform for reporting lost and found items, surfacing potential matches, submitting claims, and managing recovery — built with a Node/Express backend and a vanilla HTML/CSS/JS frontend.

## Prerequisites

- Node.js

## Run Locally

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and fill in the admin credentials (and optional PostgreSQL settings — the app falls back to local SQLite if these are left blank).
3. Start the server:
   `npm run dev`

The app will be available at `http://localhost:3000`.
